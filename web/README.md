# Сканер российских вин - веб-фронтенд

Мобильный веб-модуль для портала «Своё Вино»: фото этикетки, карточка вина, а при неуверенном распознавании - кандидаты или похожие вина. Vue 3, TypeScript, Vite.

Исходники: `src/app/` — страницы и маршрутизация, `src/features/` — сценарии,
`src/services/` — API и контракты, `src/components/` — общие компоненты.
Контракт бэкенда — в [API.md](../API.md).

## Запуск

Нужен Node 18+ и бэкенд на `127.0.0.1:8080`. Dev-сервер проксирует `/api` туда, поэтому картинки вида `/api/media/...` открываются с того же origin.

```sh
cd ../backend
python3 -m pip install -r requirements-api.txt
python3 -m wineid.api
```

```sh
npm install
npm run dev
```

Приложение: http://localhost:5173. Удобнее смотреть в мобильном viewport (390×844) или с телефона в одной сети: `npm run dev -- --host`.

```sh
npm run type-check
npm run test
npm run build
npm run preview
```

## Переменные окружения

Читаются через `import.meta.env`, типы - в `env.d.ts`. Шаблон - `.env.example`, локальные значения - `.env.development`.

| Переменная | По умолчанию | Назначение |
| --- | --- | --- |
| `VITE_API_BASE_URL` | `/api` | Базовый путь API |
| `VITE_API_TOKEN` | пусто | `Authorization: Bearer`, если на бэкенде задан `WINE_TOKEN` |
| `VITE_IMAGE_MAX_SIDE` | `1280` | Большая сторона фото после ресайза, px |
| `VITE_IMAGE_QUALITY` | `0.85` | Стартовое качество JPEG |
| `VITE_IMAGE_TARGET_BYTES` | `512000` | Целевой размер файла; качество понижается итеративно |
| `VITE_SCAN_TIMEOUT_MS` | `70000` | Минимум 70 с (бюджет backend из RUN_GUIDE.md — 60 с) |
| `VITE_SOMMELIER_TIMEOUT_MS` | `6000` | Таймаут блока сомелье, после него - текст на клиенте |
| `VITE_DEBUG_PANEL` | `false` | Панель метрик. Иначе она открывается по `?debug=1` |
| `VITE_PORTAL_BASE_URL` | `https://vino-svoe.ru` | Базовый URL ссылок «Поделиться» |

## API

- `POST /api/recognize` - распознавание этикетки
- `GET /api/wines/{slug}` - карточка
- `POST /api/search` - если распознавание вернуло `unknown` без кандидатов, но OCR отдал текст

`accepted` открывает карточку, `ambiguous` - карточку и шторку кандидатов, `unknown` - экран похожих, `unreadable` и ошибка пайплайна - экран повторной съёмки.

`scanId` создаёт браузер и хранит результат в `sessionStorage` (последние 12). Повторное открытие `?scan=` не запрашивает бэкенд: фото там не сохраняется.

Если у карточки пустой `media_url`, показывается `public/bottles/placeholder.svg`.

Сомелье и форма «Предложить вино» не ходят в сеть: сомелье отвечает текстом на клиенте, отправка предложения только подтверждается на экране. События пишутся в `console.debug`.

В карточке с бэкенда нет региона, описания, крепости, температуры, блюд и рейтингов: этих полей нет в `WineCard`. Пустые блоки скрываются. `score` в debug-панели - балл ранжирования 0–100, делённый на 100.

## Маршруты

| Маршрут | Экран | Параметры |
| --- | --- | --- |
| `/scan` | Сканер. `/` редиректит сюда | `?source=camera\|gallery` - фокус на кнопке; `?debug=1` |
| `/wines/:slug` | Карточка вина | `?scan=<scanId>` - блоки скана и шторка `uncertain`; `?debug=1` |
| `/scan/:scanId/similar` | Похожие и альтернативы | `?debug=1` |

Любой другой путь редиректит на `/scan`.

## Ограничения

- Браузер не открывает камеру без жеста пользователя, поэтому `?source=camera` только фокусирует кнопку.
- «Сканировать» открывает живой видоискатель. Если камеры нет или доступ уже запрещён, сразу открывается системная камера. Если пользователь отклонил запрос разрешения, сообщение не показывается: следующий тап открывает системную камеру.
- Ресайз и EXIF-ориентация зависят от `createImageBitmap` и `canvas`. HEIC декодируется, если его поддерживает браузер: iOS Safari - да, десктопный Chrome - нет.
- Web Share API доступен только по HTTPS или на localhost. Иначе ссылка копируется в буфер обмена.
