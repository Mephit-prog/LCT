# 05. CLIP: проверяем полезность визуального rerank

**Статус:** offline rerank/fusion реализован на Jina CLIP v2; независимый выигрыш не измерен, HTTP его не использует. Актуальные открытые задачи — [STATUS.md](STATUS.md); [CLIP — план улучшений](clip_review_improvement.md) сохраняет исторические findings и исследовательские рекомендации.

## Условие старта

Нужны **вручную проверенные** пары wine↔reference ROI и независимые query ROI; неверная gallery испортит оценку модели. CLIP сравнивает изображения этикеток (image-to-image), не вкусовые описания. Он не гарантирует чтения маленькой цифры урожая. Изображения одного кадра/ресайзы не должны одновременно считаться независимым query и эталоном.

## MVP

1. Использовать текущий frozen Jina CLIP v2 с закреплёнными weights/code revisions (`wineid/jina_clip.py`); закрыть полный lock транзитивных зависимостей и вопрос лицензии CC BY-NC 4.0 до применения. Query и gallery обрабатывать одинаково; native preprocessing против aspect-preserving padding сравнить отдельно, не считать padding уже внедрённым. Сохранить embeddings эталонов offline с версией. Для текущего размера gallery хватит точного матричного сравнения, без ANN. OpenCLIP остался только в отдельном CAM-эксперименте; прежние OpenCLIP индексы/policy несовместимы.
2. Для каждого wine_id из text Top-K взять максимальный cosine по его **совместимым по роли** проверенным эталонам. Сохранять лучший reference и число доступных эталонов; отсутствующее изображение — missing feature, не score 0. Cosine и `(cosine+1)/2` не являются вероятностями.
3. На **одном и том же** validation-наборе сравнить text-only с CLIP-rerank и простым fusion: conditional accuracy при GT∈K, безусловную exact-slug accuracy, долю случаев, где CLIP испортил правильный text top-1, unknown false accepts и задержку. Если CLIP не помогает или не укладывается в deadline — text-only остаётся baseline; не заявлять визуальную верификацию.
4. Решение `accepted` выдавать только при достаточном evidence по проверенной на validation политике; похожие этикетки соседних урожаев без читаемого различия → `ambiguous`, не случайный slug. Нет эталона/плохой ROI/unknown → отказ или отдельно проверенный text-only режим; не подменять отсутствующую визуальную оценку уверенностью. До калибровки `confidence_calibrated=null`.

## Опции после измерений

Visual-global поиск при плохом OCR может возвращать правильный SKU вне текстового K, но требует отдельной проверки unknown и порогов. Калибратор, сложный reranker и fine-tuning вводить лишь при достаточном числе независимых размеченных query; train/calibration/policy/test не смешивать. Смена модели/preprocessing требует пересборки gallery и повторной оценки. CLIP+GradCAM для локализации — [отдельный эксперимент](additional_label_segmentation.md), не обязательный шаг этого плана.

**Приёмка MVP:** корректные версии/размерности embedding, тесты отсутствующего эталона, разных ролей, одинаковых дизайнов, unknown и несовместимой gallery; отчёт об улучшении **и ухудшениях** относительно text-only. Не заявлять precision 99% по десяткам кадров: указывать знаменатель и доверительный интервал.
