# Лицензии и решения (STATUS.md B07)

**Статус: черновик. Юридическая проверка не завершена.** Этот документ фиксирует
известные ограничения и открытые решения; он не является юридическим заключением.
Перед публикацией результатов/продакшеном нужен отдельный review владельца и
юридической роли (см. `plans/STATUS.md` B07/B10).

## Веса и модели

| Компонент | Лицензия | Решение / риск |
|---|---|---|
| `jinaai/jina-clip-v2` (веса) | **CC BY-NC 4.0** | Некоммерческий baseline. Коммерческое on-prem использование требует отдельного разрешения Jina. Для коммерческой публикации — модель с разрешающей лицензией (например, SigLIP 2 Apache-2.0) или лицензия Jina. |
| HF `trust_remote_code=True` | код исполняется на машине | Требует отдельного approval `--allow-remote-code`; флаг не отменяет лицензию. Основной HF code snapshot закреплён commit SHA в `wineid/jina_clip.py`, но полного lock транзитивных зависимостей нет. |
| OpenCLIP ViT-B/16 (`wineid/clip_roi.py`) | отдельный legacy Grad-CAM эксперимент | Не заменяет энкодер Jina текущей gallery; не подключён к серверу. |
| Jina-OCR-v1 (внешний, если рассматривается) | CC BY-NC 4.0 | Только research; отдельная коммерческая лицензия. |
| Mistral OCR API | коммерческий внешний API | Передача ROI вовне допустима только при согласовании data retention/цены/схемы; ключ в env, не в JSON. Реальный canary не запускался. |
